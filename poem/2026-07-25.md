# Poems for 2026-07-25

Three poems. Today's poems address a specific reader — the second
buyer of the seller's JAR. Someone who paid the same operator,
received the same Google Drive share, opened the same folder marked
"full source code", and found, under `gnu/trove/`, the same nine
hundred files with single-letter names on every class and every
method. Earlier entries on this shelf sat with the shape of the case
as it looked from the inside — the restoration, the equivalence at
the depth, the mosaic on the seller's face, the *preferred form for
modification*, the side door at *for now*, the constant pool's small
numbered table at the side of each class, the folder the JVM would
not let him rename, the recipe left on the shelf, the deed filed
beside the body, the Coda's two small songs, the shelf that writes
in those same two forms one morning at a time, the interval the
shelf itself took off, the vigil that returned. Today the shelf
turns outward. The other buyer has not yet appeared in an issue on
this repo. The invitation in the README — *Open an issue on this
repo and I will tell you in private* — has not been taken up. The
pixels on the seller's face have held for three months of
uninterrupted public air; the `LICENSE` at the head of the tree has
not moved; the two reconstruction folders still sit side by side;
the one file the pipeline did not close on is still named in
absentia. But the shelf was, in part, for that second buyer — the
person who paid the seller and got the same envelope, and would
have had to run the same ten hours of pipeline themselves if the
shelf had not existed to save them the trip. Today's poems address
that person directly.

## I. For the Second Buyer *(English)*

If you arrived here holding the same JAR —
the same Google Drive share,
the same folder labelled *full source code* that was not source code,
the same nine hundred files under `gnu/trove/`
with single-letter names on every class and every method —
this folder is what you were going to have to build.

You do not have to build it.

Someone else stood at the threshold you are standing at,
argued for the same length of time with the same operator,
declined the reply he was going to give again,
and turned the ten hours over to a machine
that returned nine hundred and four files by morning
with the names put back.

The names in `trove-de-obfuscate-mid-stage/`
are not names anyone made up.
They are the names Eric D. Friedman
gave the library twenty-some years ago,
kept by the `trove4j-3.0.3.jar`
the seller himself shipped
next to his product on the same classpath —
the key sitting in the same room as the lock.
The check that these are the same names
is not on my say-so.
It is a bytecode diff, gated by a token-stream check,
and you can run it yourself.

The six wrappers at the seam
took a second pass, by hand,
because the folder had to be renamed on disk
and the pass was small enough for people.
The `justfile` in `trove-de-obfuscate-final-stage/`
is the receipt. You do not have to run that pass either.

There is one file this repository does not contain:
`handeval/PloHandEvaluator.java`,
seventy-four kilobytes,
which the pipeline did not close on.
If you have that file in your bag —
open an issue.
We can compare notes.

The seller has not written since April.
The pixels on his face have not slipped.
The `LICENSE` at the head of the tree is unmoved.
The record does not require you to arrive
to be a record.

But it was, in part, for you.

You can go now — take the deobfuscated tree, use it,
and never say a word.
Or you can stay and open the issue and we can compare handles.
Either is fine.

What was owed you was owed you by him.
The debt he did not settle
has been settled by someone standing where you would have stood,
so that when you got here
the standing would already have been done.
